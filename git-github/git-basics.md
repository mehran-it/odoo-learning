# Git and GitHub Fundamentals

## 1. Git
Git is a version control system that tracks changes in files.

## 2. GitHub
GitHub is an online platform for hosting Git repositories.

## 3. Repository
A repository contains project files and their version history.

## 4. Working Directory
The working directory is where I create and edit files.

## 5. Staging Area
The staging area contains changes selected for the next commit.

## 6. Commit
A commit records a snapshot of staged changes.

## 7. Branch
A branch provides a separate line of development.

## 8. Remote
A remote is a reference to another repository, such as GitHub.

## 9. Essential Commands

- `git status` — Check repository status.
- `git add` — Stage changes.
- `git commit` — Record staged changes.
- `git push` — Upload commits to GitHub.
- `git pull` — Fetch and integrate remote changes.
- `git clone` — Copy a remote repository locally.
